# アプリ機能・仕様

## 1. 機能・ページ構成

アプリ名：Skyture

| 機能 | 対応するページ | 内容 |
| --- | --- | --- |
| 今日の絵画 | 今日の絵画ページ | 出力時点の現在地の天気・時間帯に合う美術作品を1枚出力する |
| 過去の作品の振り返り | ギャラリーページ | 過去に出力した作品を閲覧する |
| 世界の都市の絵画 | 地球儀ページ | 世界の主要都市の天気・時間帯に合う作品を1日1回選定し、3Dの地球儀で閲覧する |

## 2. 今日の絵画ページ

### 判定・選定ルール

- ボタン操作後に現在地を取得し、Open-Meteoから現在の気象情報を取得する。
- 天気コード0・1は晴、2・3・45・48は曇、51〜67・80〜82は雨、71〜77・85・86は雪、95・96・99は嵐に対応させる（各範囲の有効なWMOコードを使用）。
- 日の出・日の入りの前後1時間は「朝・夕」とし、それ以外はAPIの昼夜情報で判定する。日の出・日の入りがない場合もAPIの昼夜情報を使う。
- `src/data/artworks.json` の分類済み作品を使用する。作品の再分類は行わない。
- 天気・時間帯の両方が一致する作品からランダムに1枚選ぶ。一致候補がない場合は全作品からランダムに選ぶ。
- 出力作品と取得時の天気・時間帯・出力日時をlocalStorageに保存し、同日中は再読み込み後も同じ作品を表示する。端末の翌日0時から再出力できる。
- 位置情報・天気の取得失敗は再試行できるようにし、失敗時には当日の出力枠を消費しない。

### 作品の出力

1. 位置情報の利用許可を求め、現在地の緯度・経度を取得する。
2. 位置情報を許可しない場合は、一覧から都市を選択する。
3. 対象地点の出力時点の天気・時間帯を取得する。
4. 天気・時間帯を共通のカテゴリに分類する。
5. 該当カテゴリの作品を1枚選び、表示する。
6. 出力した作品を履歴に自動保存する。

### 出力前の画面

- ヘッダー下に36pxの余白を設け、「今いる場所の天気と時間に合わせて、ぴったりの絵画を一枚おすすめします。」を通常の太さ・左寄せで表示する。
- 中央は空け、下部に「今日の空をみる」ボタン（ピンクから紫のグラデーション、白い内枠とカプセル形状）と、次の絵画を出力できるまでの残り時間を表示する。
- 出力可能なタイミングは毎日0時にリセットする。日付・0時の判定には端末の現地時間を使用する。
- 残り時間は「次の生成まで」と表示し、端末の次の0時までをカウントダウンする。
- 残り時間表示から上の出力ボタン、下のナビゲーションまでの余白は、それぞれ22pxに揃える。

### 表示内容

トップページには生成後も作品カードを表示しない。生成完了時は背景を暗くするモーダルを開き、指定のGLBモデル `public/models/frame.glb` の額縁内に作品を表示する。GLTFLoaderで直接読み込み、Frameの材質を維持する。Pictureメッシュに作品画像を適用する。初期姿勢は正面で、自動回転は行わない。操作には参考プロジェクト `/Users/haruki/Developer/project/react/frame` と同じThree.jsのOrbitControlsを使用し、enableDamping=true・dampingFactor=0.06・enablePan=falseとする。モデルではなくカメラを周回させ、毎フレームcontrols.update()を呼んで滑らかに減衰させる。左右の周回は無制限、上下はOrbitControls標準の0〜πとする。ピンチ・ホイールで拡大縮小でき、ズーム範囲は参考実装と同じ相対比率にする。ドラッグ感度は参考実装の画面全高に対する指の移動量に合わせる。現在の2作品は美術館の元画像をアプリ内に保存して同一配信元から読み込み、ブラウザの外部取得失敗を回避する。JSONの出典URL・分類は維持する。画像は縦横比を保ってキャンバス面に収める。閉じるボタン・Escapeキーで閉じられ、背面はスクロールしない。本番でも生成済み作品はボタンから再表示できる。作品データの保存は継続する。キャプションには `src/assets/plate.glb` をモデル本来の横長の向きで使用し、額縁の下に正面固定で配置する。プレートは額縁より小さく表示し、幅は表示領域の78%・280px・画面高の37%のうち最小の値を上限にする。額縁とは独立して描画し、ドラッグしてもプレートは回転しない。ベベルを含むモデル形状と材質を維持し、暗いスタジオと細い照明パネルの環境反射・斜めの光・落ち影を使用し、正面全体を白くする反射は避ける。モデルはViteのアセットURLで配信し、更新時にキャッシュが切り替わるようにする。視点は正面で固定する。画面上にドラッグの操作案内は表示しない。プレートは黒系のGLBの色・金属度・粗さを維持し、文字は白、情報ラベルと区切り線は薄い白系で表示する。透視投影とスタジオ環境の映り込みで反射に濃淡をつけ、作品名・作者・制作年を表示し、その下に「天気」「時間帯」「気温」のラベルと値を3列で整理したHTMLを重ねる。美術館へのリンクと、条件不一致時の全作品選定の説明文は表示しない。以下は作品を閲覧する際の情報とする。

- 作品画像
- 出力時点の天気・気温・時間帯
- 作品名、作者、制作年、所蔵美術館
- 美術館の作品ページへのリンク

## 3. ギャラリーページ

- 過去に出力した作品を日付ごとに一覧表示する。
- 保存した作品を選択すると、作品画像と作品情報を閲覧できる。
- 履歴はlocalStorageに保存し、ページの再読み込み後も閲覧できるようにする。

### 保存する情報

- 出力日時
- 出力した作品の識別情報
- 作品の再表示に必要な画像・作品情報

## 4. 地球儀ページ

### 都市ごとの作品の選定

1. 世界の主要都市を対象に、1日1回、各都市の天気・時間帯を取得する。
2. 時間帯は各都市の現地時刻を基準に判定する。
3. 各都市の天気・時間帯を共通のカテゴリに分類する。
4. 各都市のカテゴリに合う美術作品を1枚ずつ選ぶ。
5. 都市ごとの作品を3Dの地球儀から閲覧できるようにする。

### 表示内容

- 3Dの地球儀
- 対象となる主要都市の位置
- 都市ごとに選定した作品
- 都市名、取得時点の天気・時間帯
- 作品名、作者、制作年、所蔵美術館
- 美術館の作品ページへのリンク

## 5. 天気・時間帯の分類

気象情報と作品を、次の共通カテゴリで対応付ける。

| 分類軸 | カテゴリ |
| --- | --- |
| 天気 | 晴・曇・雨・雪・嵐 |
| 時間帯 | 昼 / 朝・夕 / 夜 |

時間帯の分類は「昼」「朝・夕」「夜」の3種類とし、天気5種類との組み合わせで全15カテゴリを使用する。

今日の絵画と世界の主要都市の絵画には、同じ分類と作品選定の仕組みを使用する。

## 6. 作品データ・API連携

### 作品データの準備

- Art Institute of ChicagoとThe Metのコレクションから、空に関係するパブリックドメインの作品を収集する。
- 作品画像を画像認識AI（CLIP）と色分析で仮分類し、人が確認・修正する。
- 作品情報と天気・時間帯の分類を、共通形式のJSONにまとめる。

### 使用するサービス

| サービス | 用途 |
| --- | --- |
| Open-Meteo Forecast API | 対象地点の天気・気温・時間帯の判定に必要な気象情報を取得する |
| Art Institute of Chicago API | 作品情報と画像の識別情報を取得する |
| The Met Collection API | 作品情報と画像URLを取得する |

### 作品の表示処理

対象地点の緯度・経度 → 気象情報の取得 → 天気・時間帯の分類 → 分類済みJSONから作品を選定 → 美術館の画像サーバーから画像を表示する。

作品データは事前に準備し、作品の出力時は分類済みデータから選定する。トップページにはOpen-Meteoの出典リンクを表示しない。

## 7. 共通の表示・操作

- 共通ヘッダーにはロゴ画像 `public/images/skyture-art-wordmark.png`と情報アイコンを表示する。
- ヘッダーは上部に余白を設け、Shantell Sansの手書き感に小さな筆と絵の具のアクセントを添えた透過ロゴ画像は縦横比を保ち、幅160pxを上限に表示する。本文などの文字にもNoto Sans JPを使用する。
- 情報アイコンは説明モーダル用の配置のみとし、現時点では開閉処理・モーダル本体を実装しない。

- 3つのページ間を移動できるようにする。
- 各ページに共通のLiquid Glassナビゲーションを表示する。項目は「今日の絵画」「ギャラリー」「地球儀」とし、Lucideアイコンを使用する。ガラス表現はライブラリを使わずCSSで実装する。
- ナビゲーションでは現在のページを選択状態として表示する。選択ハイライトはページ切り替え時に滑らかに移動し、タップ時に軽く縮む。動きを減らす端末設定ではアニメーションを無効にする。
- ナビゲーションと残り時間のガラス面は、彩度・明るさを等倍にし、着色・曇り・ぼかしを加えず、背景をそのまま透過させ、縁の反射と薄い影でガラスの輪郭を表現する。
- 生成中は背景を暗くし、中央に回転するリングと処理段階に対応したアイコンを表示する。「現在地を取得しています」「今の空を確認しています」「今日の一枚を準備しています」と進行に合わせて切り替える。取得中に背面の操作・スクロールを受け付けず、失敗時はローディングを終了して再試行できるようにする。意図的な待ち時間は入れない。動きを減らす端末設定ではリングを静止する。
- 位置情報・気象情報・画像の取得に失敗した場合は、原因と再試行の方法を表示する。
- 位置情報を取得できない場合は、都市選択から利用できるようにする。
- 画面の最大幅は430pxとし、PCでも中央にスマートフォン向けの幅で表示する。
- 全ページの背景に `public/rive/background.riv` を表示し、自動でループ再生する。
- 背景は画面領域を覆うように表示し、ページの操作を妨げないようにする。

## 8. 詳細を定める項目

| 項目 | 決定する内容 |
| --- | --- |
| 作品の選定 | 過去の日に出力した作品との重複の扱い |
| 作品数 | 15カテゴリごとの必要作品数と、該当作品がない場合の動作 |
| 履歴 | 同じ日の複数作品の表示方法、保存上限、削除方法 |
| 対象都市 | 地球儀に表示する主要都市の一覧 |
| 地球儀の更新 | 1日1回の取得時刻、日付の基準、取得を実行するタイミング、結果の保存方法 |
| 地球儀の操作 | 回転・拡大縮小・都市の選択方法と、作品の表示方法 |
