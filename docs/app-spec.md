# アプリ機能・仕様

## 1. 機能・ページ構成

アプリ名：Skyture

| 機能 | 対応するページ | 内容 |
| --- | --- | --- |
| 今日の絵画 | 今日の絵画ページ | 出力時点の現在地の天気・時間帯に合う美術作品を1枚出力する |
| 過去の作品の振り返り | ギャラリーページ | 過去に出力した作品を閲覧する |
| 世界の都市の絵画 | 地球儀ページ | 世界の主要都市の天気・時間帯に合う作品を1日1回選定し、3Dの地球儀で閲覧する |

## 2. 今日の絵画ページ

### 判定・選定ルール

- ボタン操作後に現在地を取得し、Open-Meteoから現在の気象情報を取得する。
- 天気コード0・1は晴、2・3・45・48は曇、51〜67・80〜82は雨、71〜77・85・86は雪、95・96・99は嵐に対応させる（各範囲の有効なWMOコードを使用）。
- 日の出・日の入りの前後1時間は「朝・夕」とし、それ以外はAPIの昼夜情報で判定する。日の出・日の入りがない場合もAPIの昼夜情報を使う。
- `src/data/artworks.json` の分類済み作品を使用する。作品の再分類は行わない。
- 天気・時間帯の両方が一致する作品からランダムに1枚選ぶ。一致候補がない場合は全作品からランダムに選ぶ。
- 出力作品と取得時の天気・時間帯・出力日時をlocalStorageに保存し、同日中は再読み込み後も同じ作品を表示する。端末の翌日0時から再出力できる。
- 位置情報・天気の取得失敗は再試行できるようにし、失敗時には当日の出力枠を消費しない。
- 天気取得の失敗はタイムアウト・通信障害（ブラウザではCORS等と判別できない場合を含む）・アクセス制限（429）・APIのHTTPエラー・データ形式不備・分類不可に分けて表示する。HTTPエラーはステータスコードも表示する。
- 天気取得は通信エラー・タイムアウト・HTTP 408/429/500/502/503/504の場合に最大2回自動再試行する（初回を含め3回）。待機は通常1秒・2秒。APIがRetry-Afterを指定した場合は優先し、15秒を超える待機が必要なら自動再試行を止め、時間をおいて再試行するよう案内する。1回の応答待ちは15秒。その他の4xx・データ不備・分類不可は自動再試行しない。

### 作品の出力

1. 位置情報の利用許可を求め、現在地の緯度・経度を取得する。
2. 位置情報を許可しない場合は、一覧から都市を選択する。
3. 対象地点の出力時点の天気・時間帯を取得する。
4. 天気・時間帯を共通のカテゴリに分類する。
5. 該当カテゴリの作品を1枚選び、表示する。
6. 出力した作品を履歴に自動保存する。

### 出力前の画面

- ヘッダー下に36pxの余白を設け、「今いる場所の天気と時間に合わせて、ぴったりの絵画を一枚おすすめします。」を通常の太さ・左寄せで表示する。
- 中央は空け、下部に「今日の空をみる」ボタン（ピンクから紫のグラデーション、白い内枠とカプセル形状）と、次の絵画を出力できるまでの残り時間を表示する。
- 出力可能なタイミングは毎日0時にリセットする。日付・0時の判定には端末の現地時間を使用する。
- 当日生成済みの場合は「次の生成まで」と表示し、端末の次の0時までをカウントダウンする。未生成で生成可能な場合は残り時間の代わりに「生成できます」と表示する。
- 残り時間表示から上の出力ボタン、下のナビゲーションまでの余白は、それぞれ22pxに揃える。

### 表示内容

トップページには生成後も作品カードを表示しない。生成完了時は背景を暗くする共通の作品モーダルを開き、指定のGLBモデル `public/models/frame.glb` の額縁内に作品を表示する。GLTFLoaderでFrameの材質を維持し、Pictureメッシュに縦横比を保った作品画像を適用する。現在の2作品はアプリ内に保存した画像を読み込み、JSONの出典URL・分類は維持する。

トップページ・ギャラリー・地球儀ページは共通の3D作品ビューアーを使用する。作品名・作者・制作年・天気・時間帯・気温を額縁の裏面に直接表示し、キャプションプレートは使用しない。絵画をタップするたびに同じ方向へ半回転し、表裏を切り替える。下に「- タップして作品情報をみる -」を常時表示し、裏面では「- タップして絵画にもどる -」とする。動きを減らす設定では即時切り替える。作品モーダルは閉じるボタン・Escape・外側のタップで閉じられ、背面はスクロールしない。美術館へのリンクと条件不一致時の説明文は表示しない。

その日に生成済みの場合はボタンを不透明度45%の薄い表示で無効化し、同じ作品を再表示しない。端末の翌日0時に再び生成可能にする。作品データの保存は継続する。

- 作品画像
- 出力時点の天気・気温・時間帯
- 作品名、作者、制作年、所蔵美術館
- 美術館の作品ページへのリンク

## 3. ギャラリーページ

- ページ上部に「ギャラリー」の見出しや選択日の独立した日付表示は設けない。日付は折れ線グラフ内に表示する。

- 最新の記録を初期選択し、3D額縁と作品画像を中央に大きく表示する。ギャラリーではプレートを使わず、額縁の背面に作品名・作者・制作年・天気・時間帯・気温を直接表示する。
- 絵画のタップで回転アニメーションにより表裏を切り替える。回転は常に同じ方向へ半回転ずつ進み、表面へ戻すときも逆回転しない。絵画のすぐ下に「- タップして作品情報をみる -」を常時表示し、裏面では「- タップして絵画にもどる -」とする。専用ボタンや自動回転は設けない。別の日の作品は表面から表示する。動きを減らす設定では即時切り替える。今日の絵画モーダルと共通の作品ビューアーを使用する。
- 画面下部には背景シェードを設けない。タップ案内の文字に控えめな影を付けて読みやすくする。
- 下部に横軸が日付、縦軸が取得時の気温の折れ線グラフを表示する。日付間隔は一定とし、横スクロールできる。
- グラフはページ下部に配置し、ナビゲーションまでの余白はトップページと同じ22pxに揃える。端末のセーフエリアも共通の計算を使用する。
- 気温目盛り用の余白はグラフの左右に同じ幅で確保し、選択点と中央のガイド線をグラフエリア全体の中央に揃える。
- グラフの中央に最も近い記録のある日を選択し、スクロール中も作品を切り替える。スクロール後は最寄りの記録の点が中央に揃う位置へ自動で移動する。日付のタップ、左右ボタン、サムネイルによる作品切り替えは設けない。
- 記録のない日は点を表示せず、線を途切れさせる。停止・選択の対象にはせず、「記録なし」の表示も設けない。
- 同じ日に複数の保存記録が残っている場合は、その日の最後の記録を表示する。
- 履歴がない場合は空のギャラリーを案内する。

- 過去に出力した作品を日付ごとに一覧表示する。
- グラフの横スクロールで日付を選択し、作品画像と作品情報を閲覧できる。
- 履歴はlocalStorageに保存し、ページの再読み込み後も閲覧できるようにする。
- 履歴は保存時の作品情報を保持し、選定用JSONから作品が削除されても閲覧できるようにする。

### 保存する情報

- 出力日時
- 出力した作品の識別情報
- 作品の再表示に必要な画像・作品情報

## 4. 地球儀ページ

### 都市ごとの作品の選定

- 対象は東京・ロンドン・パリ・ニューヨーク・シドニー・シンガポール・ドバイ・ケープタウンの8都市。
- バックエンドは使用せず、その端末で当日初めて地球儀ページを開いた際に各都市の天気と作品を取得し、localStorageに保存する。日付の切り替えは端末の0時を基準とする。当日の保存済み作品は再選定しない。取得に失敗した都市は再試行できる。
- 当日の保存済み作品はすぐに表示し、各都市の取得結果を完了した順に反映する。他都市の遅延・失敗によって表示を待たせない。

1. 世界の主要都市を対象に、1日1回、各都市の天気・時間帯を取得する。
2. 時間帯は各都市の現地時刻を基準に判定する。
3. 各都市の天気・時間帯を共通のカテゴリに分類する。
4. 各都市のカテゴリに合う美術作品を1枚ずつ選ぶ。
5. 都市ごとの作品を3Dの地球儀から閲覧できるようにする。

### 表示内容

- COBEの3D地球儀を中央に大きく配置する。暗い海・明るい陸地の点と控えめな発光を使用し、ページ見出しや都市カード一覧は設けない。
- 最初はゆっくり自動回転し、タッチ・ドラッグ・キーボード操作中は停止する。最後の操作から3秒間触られなければ自動回転を再開する。作品モーダルの表示中は停止し、閉じてから3秒後に再開する。ドラッグで地球儀の向きを変えられる。動きを減らす設定では自動回転しない。
- 各都市の位置に小さな作品画像と都市名を常時表示する。作品画像をタップすると共通の作品モーダルを開く。作品情報・気象情報は額縁の裏面に表示し、都市名と取得時の現地日時も裏面にまとめる。タップで情報を閲覧できる案内を表示する。画像は地球儀の回転に追従し、裏側の都市は隠す。近接する都市は画像の重なりを避け、位置との対応を線で示す。取得失敗時は案内と再試行を表示する。
- 地球儀の下に操作案内文は表示せず、「左へ回す」「自動回転の停止／再開」「右へ回す」の3ボタンを配置する。停止ボタンで止めた場合は3秒後の自動再開も無効にし、再開ボタンを押すまで停止を維持する。停止中もドラッグ・左右ボタンで向きを変えられる。
- 回転操作の並びに「元の位置に戻す」ボタンを追加し、地球儀の向き・傾きを初期位置へ戻す。自動回転の停止／再開設定は維持し、再生中であれば操作後3秒で自動回転を再開する。
- 地球儀上の作品は白い余白を持つポラロイド風カードとし、下側の白い余白に都市名を表示する。控えめな傾きと落ち影で立体感を付ける。
- 作品カードをタップしてモーダルを読み込む際、回転操作ボタンの下には準備中のメッセージを表示しない。作品の読み込み状態はモーダル内のスピナーで表示する。
- 都市の位置は青い点で明示し、カードは点より上に浮かせて点を隠さない。カード下端と位置点を細い線で結ぶ。

- 3Dの地球儀
- 対象となる主要都市の位置
- 都市ごとに選定した作品
- 都市名、取得時点の天気・時間帯
- 作品名、作者、制作年、所蔵美術館
- 美術館の作品ページへのリンク

## 5. 天気・時間帯の分類

気象情報と作品を、次の共通カテゴリで対応付ける。

| 分類軸 | カテゴリ |
| --- | --- |
| 天気 | 晴・曇・雨・雪・嵐 |
| 時間帯 | 昼 / 朝・夕 / 夜 |

時間帯の分類は「昼」「朝・夕」「夜」の3種類とし、天気5種類との組み合わせで全15カテゴリを使用する。

今日の絵画と世界の主要都市の絵画には、同じ分類と作品選定の仕組みを使用する。

## 6. 作品データ・API連携

### 作品データの準備

- Art Institute of ChicagoとThe Metのコレクションから、空に関係するパブリックドメインの作品を収集する。
- 作品画像を画像認識AI（CLIP）と色分析で仮分類し、人が確認・修正する。
- 作品情報と天気・時間帯の分類を、共通形式のJSONにまとめる。

### 使用するサービス

| サービス | 用途 |
| --- | --- |
| Open-Meteo Forecast API | 対象地点の天気・気温・時間帯の判定に必要な気象情報を取得する |
| Art Institute of Chicago API | 作品情報と画像の識別情報を取得する |
| The Met Collection API | 作品情報と画像URLを取得する |

### 作品の表示処理

対象地点の緯度・経度 → 気象情報の取得 → 天気・時間帯の分類 → 分類済みJSONから作品を選定 → 美術館の画像サーバーから画像を表示する。

作品データは事前に準備し、作品の出力時は分類済みデータから選定する。トップページにはOpen-Meteoの出典リンクを表示しない。

## 7. 共通の表示・操作

- 共通ヘッダーにはロゴ画像 `public/images/skyture-art-wordmark.png`と情報アイコンを表示する。
- ヘッダーは上部に余白を設け、Shantell Sansの手書き感に小さな筆と絵の具のアクセントを添えた透過ロゴ画像は縦横比を保ち、幅160pxを上限に表示する。本文などの文字にもNoto Sans JPを使用する。
- 情報アイコンから「アプリについて」という見出しの説明モーダルを開く。ナビゲーションと同じ共通の透明ガラス表現を使用し、「ログイン不要」「絵画の取得は1日1回まで」を案内する。端末の時間で毎日0時に再取得できる旨も表示する。閉じるボタン・Escapeキー・モーダルの外側のタップで閉じられ、表示中は背景を操作・スクロールできない。

- 3つのページ間を移動できるようにする。
- 各ページに共通のLiquid Glassナビゲーションを表示する。項目は「今日の絵画」「ギャラリー」「地球儀」とし、Lucideアイコンを使用する。ガラス表現はライブラリを使わずCSSで実装する。
- ナビゲーションでは現在のページを選択状態として表示する。選択ハイライトはページ切り替え時に滑らかに移動し、タップ時に軽く縮む。動きを減らす端末設定ではアニメーションを無効にする。
- ナビゲーションと残り時間のガラス面は、彩度・明るさを等倍にし、着色・曇り・ぼかしを加えず、背景をそのまま透過させ、縁の反射と薄い影でガラスの輪郭を表現する。
- 生成中は背景を暗くし、中央の天気アイコン（CloudSun）と、その周囲のシンプルな円形スピナーだけを表示する。テキスト・進行状況バー・装飾の点は表示しない。スピナーは薄いリングの一部を白くし一定速度で回転させる。取得中に背面の操作・スクロールを受け付けず、失敗時はローディングを終了して再試行できる。意図的な待ち時間は入れない。動きを減らす端末設定ではリングを静止する。
- 位置情報・気象情報・画像の取得に失敗した場合は、原因と再試行の方法を表示する。
- 位置情報を取得できない場合は、都市選択から利用できるようにする。
- 画面の最大幅は430pxとし、PCでも中央にスマートフォン向けの幅で表示する。
- 作品情報と選択日の気温はスクリーンリーダーでも読めるようにする。3D作品表示はリサイズ時に額縁全体が収まるよう調整する。
- 額縁・地球儀が静止している間は不要な連続描画を行わない。ギャラリーで作品を切り替えても3Dシーンと額縁モデルは再利用する。
- 全ページの背景に `public/rive/background.riv` を表示し、自動でループ再生する。
- 背景は画面領域を覆うように表示し、ページの操作を妨げないようにする。

## 8. 詳細を定める項目

| 項目 | 決定する内容 |
| --- | --- |
| 作品の選定 | 過去の日に出力した作品との重複の扱い |
| 作品数 | 15カテゴリごとの必要作品数と、該当作品がない場合の動作 |
| 履歴 | 同じ日の複数作品の表示方法、保存上限、削除方法 |
| 対象都市 | 地球儀に表示する主要都市の一覧 |
| 地球儀の更新 | 1日1回の取得時刻、日付の基準、取得を実行するタイミング、結果の保存方法 |
| 地球儀の操作 | 回転・拡大縮小・都市の選択方法と、作品の表示方法 |
